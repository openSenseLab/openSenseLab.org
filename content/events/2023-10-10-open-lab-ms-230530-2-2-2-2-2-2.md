Vom 07.10. – 22.10.2023 ist [Code Week](https://www.codeweek.de/) und es finden überall verschiedene Veranstaltungen rund ums Coding und Making statt.

Programmierschnittstellen (API) werden in vielen verschiedenen Systemen verwendet und ermöglichen, dass diese miteinander kommunizieren können. In diesem Workshops schauen wir uns den Aufbau einer API an und lernen Dinge z.B. Daten von einer API abzurufen oder über eine API in einer Datenbank zu speichern.
